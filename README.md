# Ecommerce Customers Linear Regression

## Project Overview

This project uses Machine Learning Linear Regression to predict yearly customer spending based on customer behaviour data.

## Dataset

The dataset contains ecommerce customer information:

- Average Session Length
- Time on App
- Time on Website
- Length of Membership
- Yearly Amount Spent

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model

Algorithm Used:

Linear Regression

### Features (X)

- Avg. Session Length
- Time on App
- Time on Website
- Length of Membership

### Target (Y)

- Yearly Amount Spent

## Project Workflow

1. Import Libraries
2. Load Dataset
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Selection
6. Train-Test Split
7. Model Training
8. Prediction
9. Model Evaluation
10. Residual Analysis

## Model Evaluation

Metrics used:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
